# 🌾 Paddy & Modern Rice Mill Dynamic Billing & Accounting System

A high-performance, real-time web application engineered for modern rice mills, paddy processing units, and agro-commodity traders. Designed specifically to calculate inward paddy weighments, milling charges, labor/handling expenses, and by-product realization dynamically every time.

---

## 🚀 Key Features

1. Dynamic Input & Calculation Engine
2. Dual Workflow Modes Supported
3. Dual Comparative View
4. Persistent History & Database
5. Printable Invoices & Thermal Slips
6. Custom Tariff & Mill Settings
7. Export Capabilities
8. Indian Currency Number-to-Words Converter

---

## 🏃 Running the Application

### 1. Launch with One Command
```bash
python start_app.py
```

### 2. Manual Startup
**Backend**:
```bash
uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

**Frontend**:
```bash
cd frontend
npm run dev
```
